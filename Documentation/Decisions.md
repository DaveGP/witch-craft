# Decisions

This document is to track decisions and the reasoning behind them throughout the project.

## Unity

01/11/2026 - Unity 6 (6000.5.3f1) with URP and the Input System, the same setup as Crewfall, so tooling and knowledge carry straight over.

## Crewfall character controller structure

01/11/2026 - The character mirrors Crewfall's layering: a `UnityInputReader` reads the controls, an `InputProvider` buffers input in Update for FixedUpdate, the character consumes it each physics step and hands it to a `CharacterMotor`, which drives an `IMovementController` and an `IActionController`. Services are found through the `ServiceLocator`, set up by the `Bootstrapper`, ticked by the `SystemManager`, and talk through the `EventBus`. The camera follows the active `IObserverTarget`.

Witch Craft is single player, so Crewfall's `CharacterNetworkController` becomes `PlayerCharacter`: same job (pull input, run the motor, expose movement state) without the server RPC and sync vars.

## Camera relative movement

01/11/2026 - Crewfall turns the character with the mouse. A 3D platformer reads better with camera relative movement and the character facing where she runs, so the motor uses `ICameraController.Forward` and `Right`, and the camera orbits freely.

## Code-built input map

01/11/2026 - `PlayerControls` builds its action map in code rather than from an `.inputactions` asset with a generated wrapper, so the project compiles from a clean checkout without an import step. It keeps the generated wrapper's shape (`playerControls.Player.Jump`), so it can be swapped for an asset later without touching the reader.

## Generated content

01/11/2026 - Like Crewfall's level builders, all data assets, prefabs and the scene are generated by editor scripts. Content is defined in readable code, re-running is safe, and there are no hand-authored scenes to merge. The cost is that art is primitive placeholders for now.

## Broom hover ceiling

01/11/2026 - Unlimited broom flight would make the platforming pointless. The broom drains a charge and can only climb a few metres above the ground below it; updrafts lift past the ceiling. Flying off a high place becomes a glide, which feels good and keeps the climbs meaningful.

## Brews judged against every recipe

01/11/2026 - The brew is scored by edit distance against all recipes, not only the selected one. This makes mistakes degrade gracefully (one wrong step is a worse potion, not nothing) and lets players discover recipes by experimenting or following a companion's description.

## Third-party assets stay local

01/11/2026 - Asset packs from Synty and the Unity Asset Store go in `Unity/Assets/ThirdParty/Synty` and `Unity/Assets/ThirdParty/AssetStore`. Git tracks those folders and a README but ignores their contents: the repo is public and the packs' licences don't allow redistributing them, and Crewfall's Synty packs blew through the Git LFS storage limit. As on Crewfall, the parts we actually use and modify get copied into the project proper, so a fresh clone still builds.

## Art swaps over placeholders

01/11/2026 - Rather than building the world from asset packs, every placeholder gets an art slot in `Assets/Resources/ArtSet.asset`. A slot's prefab replaces only the placeholder's looks at runtime; collision and behaviour stay on the placeholder. Because the packs are local only, a clone without them must still build and play: a missing prefab simply leaves the placeholder showing. It also keeps gameplay tuning independent of how big or oddly shaped a pack's models are.

## Starter hut refunds half

01/11/2026 - Unmake gave back the full cost of anything, including the starter hut the witch is given for free, so pulling the hut down was a pile of free materials and a shortcut past gathering for the first expansion. Starter pieces are flagged on their `PieceRecord` and return half their cost, rounded down; the Unmake prompt says why. Players can still clear the hut to redesign it, but never come out ahead. The bookshelf moved to level 1 so the storybook bookcase can always be rebuilt.

## The witch's art: Synty locomotion plus a casting layer, on Simple Lit

02/11/2026 - The Stellar Witch model is Humanoid, so Synty's Base Locomotion and the Human Spellcasting clips both retarget onto her. Locomotion fills the base layer; casting plays on an upper-body layer, so she can cast while running. Each spell picks one of four gestures (point, push, call, sweep) rather than one clip per spell, so new spells only need a gesture. Her materials use Unity's toon shader package, which doesn't compile on this Unity's URP and drew her magenta, so the setup tool moves the pack's materials onto URP Simple Lit in place, reading her textures from the materials' saved properties (the shader is gone), so nothing in the project refers to the toon shader; that's also light for the web build. Her hair physics (UnityChanSpringBone, MIT) is an optional package: with it installed the model's own spring bone set-up works as its author made it.

## Roofs keep a shell under their art

02/11/2026 - Art for a roof replaces only the slope; the placeholder's gable ends and ceiling stay. The pack's curved roofs have open ends, and a roof with gaps let the sky (and the rain) in. Rain now collides with buildings too, so a roof means shelter.

## Scenery that can't be picked

02/11/2026 - Scenic dressing never looks like something gatherable: no glowing mushrooms (scenic ones wear a muted, glow-free copy of the forest atlas), logs, the berry bush, the gather flowers, nettle-like ferns, the boulder rock), so players don't try to pick things they can't.

## Soft-edged ground patches

02/11/2026 - Flat discs of a different ground texture read as polka dots. A small URP shader projects the texture from above in world space (so it lines up with the ground around it) and fades each disc out over a wobbly, dithered edge. Dithering keeps the patches opaque, so they sort and receive shadows like the ground, with no transparency cost on the web.
